## 📖 About The Project

Unexpected Hard Disk Drive (HDD) and Solid-State Drive (SSD) mechanical or controller failures cause irreversible data loss and severe system downtime. Traditional monitoring systems rely on static, threshold-based firmware alerts that typically notify users only after critical sectors or files have already been corrupted.

**DriveGuard** solves this by shifting hardware maintenance from reactive replacement to proactive data preservation. It utilizes a **SMOTE-boosted Random Forest classifier** trained on operational telemetry from the public Backblaze Hard Drive Test Data repository. By analyzing physical degradation attributes (such as S.M.A.R.T. 5, 187, 188, 197, and 198), the system screens for patterns associated with terminal failure-day records.

### ✨ Key Features
* **Machine Learning Diagnostic Engine:** Evaluates daily S.M.A.R.T. telemetry using a model optimized for Recall to minimize catastrophic False Negatives.
* **Interactive Web Interface:** A clean, professional Streamlit dashboard allowing users to upload and screen their own `.csv` telemetry files.
* **Explainable AI (Hardware Dictionary):** Translates opaque machine learning triggers (e.g., S.M.A.R.T. 197) into physical root causes (e.g., magnetic platter decay, mechanical friction).
* **Demonstration Samples:** Includes hold-out test samples featuring real Backblaze records for safe platform evaluation.

## 🚀 Installation & Running Locally

To run this project on your local machine, follow these steps:

1. **Clone the repository**
   ```sh
   git clone https://github.com/your-username/DriveGuard.git
   cd DriveGuard
   ```

2. **Create a virtual environment (Optional but recommended)**
   ```sh
   python -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   ```

3. **Install the required dependencies**
   ```sh
   pip install -r requirements.txt
   ```

4. **Run the Streamlit application**
   ```sh
   streamlit run Driveguard_Prod_v4.py
   ```

The app will automatically open in your default web browser at `http://localhost:8501`.
